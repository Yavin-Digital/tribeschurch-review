# Tribes Church Review Deck (prototype)

Mobile-first, presentation-style HTML review deck summarizing two documents prepared by The Tribe Maker for Tribes Church:

1. Planning Center Workflow Map (how the five People workflows run today)
2. Planning Center vs Subsplash (recommendation, findings, seven-phase migration path, open questions)

Vanilla HTML/CSS/JS, no build step. Open `index.html`. Navigation: scroll or swipe, arrow keys, on-screen buttons, slide list menu.

No congregant personal data is included.
